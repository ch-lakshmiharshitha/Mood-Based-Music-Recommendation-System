# Mood-Based-Music-Recommendation-System 🎵
AI Project 

## CSE 311 Artificial Intelligence Course Project

### Project Overview

This project implements an AI-based music recommendation system that suggests songs based on user's current mood and preferred language using **Content-Based Filtering** with **Random Selection** algorithm.

### AI Techniques Used

- **Content-Based Filtering**: Matches songs based on mood and language tags
- **Randomized Selection**: Provides different recommendations each time
- **Natural Language Processing**: Processes mood input and generates contextual responses

### Features

- 🤖 AI-powered mood detection and song matching
- 🌍 Multi-language support (English, Turkish, Spanish, etc.)
- 🎵 Spotify integration with embedded players
- 📺 YouTube playlist generation
- 🔄 Dynamic recommendations (different songs each time)
- 📱 Responsive design for all devices
